# AVASARA final build — CV studio and acknowledgements

- Replaced the former Word-download gallery with six in-browser selectable CV/resume visual styles.
- The Browse button now focuses the style selector, and selecting a style scrolls to the editable CV fields.
- The existing CV form provides live previews, local browser storage, photo option and print/PDF export.
- Added AI development acknowledgements to README only.
- Preserved the existing opportunity database, Community tab, Academy, Tracker, automation and verification files.
