The registry is a directory of official portals. `link_only` means NO automated scraping. For an endpoint with confirmed reuse permission, set `mode` to `rss` and `feed_url` to the actual official RSS/Atom feed URL, or `mode` to `greenhouse` and `board_token` to the official employer's Greenhouse board token. Do not guess feed URLs or use a Greenhouse token for a non-Greenhouse portal. RSS/Greenhouse discoveries are REVIEW QUEUE ONLY until a human approves the individual record. Source pages and terms should be checked before enabling any importer.
